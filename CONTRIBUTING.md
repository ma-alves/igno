# Contributing

## Reporting issues

Open a GitHub issue describing the bug or feature request. Include steps to
reproduce if applicable.

## Pull requests

- Keep changes focused. Avoid unrelated refactors in the same PR.
- Run `cargo check` before submitting.
- No test framework is set up yet, but if you add one, make sure tests pass.
- Follow the existing code style, no comments unless necessary.

## Development

- `git clone` and `cargo build` should get you going for now.
